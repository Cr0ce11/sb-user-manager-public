# ADR 0025：入口发起的落地 sing-box 运行时准备

- 状态：已接受并实现，保持 dormant
- 日期：2026-08-08
- 关联：[ADR 0013](0013-controller-pinned-landing-transport.md)、[ADR 0015](0015-entry-initiated-landing-root-bootstrap.md)、[ADR 0024](0024-entry-initiated-landing-dependency-preparation.md)、[Issue #238](https://github.com/DTB201/sb-user-manager/issues/238)

## 背景

ADR 0024 已允许入口在人工核对主机身份后，为干净 Debian 12 x86_64 落地安装固定系统依赖，但后续通道引导和首次 apply 仍要求 `/usr/local/bin/sing-box` 已经存在且可信。要求管理员逐台登录下载会打断未来“一切操作在入口完成”的产品流程。

全局 sing-box 二进制也可能由其他工具或管理员管理。初始化能力不能为了方便而覆盖一个未知版本、可疑权限或内容不同的现有文件；否则一次尚未创建任何项目状态的准备动作就可能破坏外部业务。

## 决定

增加一个尚未接入菜单的入口编排函数。它验证入口控制器状态、地址、端口和落地 ID，复用 ADR 0013 的唯一 Ed25519 指纹发现与人工确认。拒绝、EOF、扫描失败均发生在 root 连接前；实际发送前再次扫描并只把同一指纹写入临时 `known_hosts`。

入口只查询 `SagerNet/sing-box` 官方 latest stable Release，并把版本限制为三段数字正式版、资产限制为 `sing-box-<version>-linux-amd64.tar.gz`、下载地址限制为该仓库的 Release 路径。GitHub Release 必须提供合法 SHA-256 digest。入口继续复用已有安全准备链：HTTPS 与 HTTPS 重定向限制、资产摘要校验、只解包精确成员、拒绝符号链接、限制二进制大小，并执行候选文件确认首行版本。任何一步失败都不会形成可发送包。

入口把候选二进制自身的 SHA-256、版本和 Base64 内容写入 600 权限的固定 Bash 包。包不得超过 128 MiB，二进制不得超过 64 MiB。通用 root 接收器先固定并核对整包摘要，再以空环境运行；SSH 继续禁用 PTY、转发、代理、跳板、复用、用户配置和主机密钥自动更新，密码或键盘交互只由 OpenSSH 直接处理。

远端包只支持 Debian 12 x86_64 root，目标固定为 `/usr/local/bin/sing-box`。它先验证固定工具、系统标识、目标目录和现有目标的类型、所有者与写权限：

1. 目标不存在时，在同目录建立随机临时文件，解码后再次核对二进制 SHA-256 与版本，设置 0755 并同步文件，再以不覆盖语义建立目标硬链接、移除临时名称并同步目录；目标若在最后一刻出现，链接操作原子失败，不会覆盖。安装后重新执行全部目标校验。
2. 目标已存在时，只有普通文件、非符号链接、root 所有、组和其他用户不可写、可执行、内容摘要和版本与入口候选完全一致，才返回 `ready`。
3. 已有目标不安全时返回 `unsafe_existing`；已有安全文件但内容或版本不同则返回 `existing_conflict`。两种情况都不 chmod、不删除、不覆盖。
4. 安装前失败只清理临时文件。安装后复检失败时，仅在目标仍是本包的精确摘要且权限可信时删除该目标；无法证明所有权时保留事实并失败关闭。

响应只能是一行严格 JSON，且必须与 SSH 退出码一致。稳定区分 `ready`、`installed`、平台不支持、已有目标不安全、已有目标冲突、固定运行工具不安全、载荷无效、安装失败、复检失败和 SSH 结果不确定。整包校验失败、空响应、额外字段、超长输出或响应与退出码不一致均不得报告成功。

## 中断与重试

本阶段不建立新的远端收据。目标从“不存在”到“官方二进制精确存在”只有一次原子替换：SSH 若在替换前断开，重试会重新安装；若在替换后、响应前断开，重试会通过摘要、版本和权限复检收敛为 `ready`。因此无需凭本地阶段猜测远端事实，也不会通过重试覆盖未知内容。

## 边界

本能力不创建 sing-box 配置、证书、AnyTLS 用户、systemd 单元、nftables 规则、Nfuse、入口状态、每落地秘密、onboarding 日志、受限账户、引导收据或 apply 数据；不选择测试版或自定义版本；不修改外部已有 sing-box。它继续保持 dormant，不接 v4、角色菜单、在线更新、服务器验收或发布。

未来落地初始化向导必须按顺序调用：ADR 0024 固定依赖准备、本决定的 sing-box 运行时准备、既有秘密与 root 通道引导、登记和首次 apply。只有向导具备完整续接和提示语义后，才允许把本能力暴露给用户。

## 验证与回退

测试覆盖官方稳定版元数据限制、本地候选摘要和版本、准备失败不暴露候选、干净安装、完全一致幂等、不同和不安全目标拒绝且原样保留、平台与固定工具拒绝、载荷损坏、安装及复检失败、严格响应、人工确认顺序和二次指纹失败。CI 同时运行私有版、分享版和 Debian 12 jq 1.6。

接入菜单前可删除本模块、定向测试和本文档，恢复 modules.list/CI 并重新生成单脚本。未来测试机若已执行安装，只能在目标仍与本次官方二进制摘要完全一致、且没有后续项目配置或服务引用时删除；否则保留并人工处理，禁止盲目删除或覆盖。
