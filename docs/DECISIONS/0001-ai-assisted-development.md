# 0001：采用产品负责人、CTO 与 Codex 分工

- 状态：已被 [`0002-ai-product-technical-lead.md`](0002-ai-product-technical-lead.md) 取代
- 日期：2026-07-16

## 背景

产品负责人没有编程经验，希望专注于产品方向，由 ChatGPT 决定技术方案，Codex 完成代码实现。

## 决定

- 产品负责人拥有产品范围、优先级、默认体验和发布接受权。
- ChatGPT 作为 CTO，将自然语言需求转成技术方案、风险、兼容策略和验收标准。
- Codex 负责仓库检查、实现、测试、文档、分支、提交、Pull Request 和测试服务器验证。
- GitHub Issue、决策记录和 Pull Request 作为长期上下文，不依赖单次聊天记忆。
- 产品行为不明确、可能丢失数据或扩大外部影响时，AI 必须暂停并请求产品负责人决定。

## 结果

产品负责人不需要审查源代码，但每次交付必须收到普通语言说明，包括用户变化、测试结果、兼容风险、恢复方式和发布建议。

2026-07-16 起，日常产品与技术领导职责按 0002 执行；本文件保留用于说明历史协作方式。
