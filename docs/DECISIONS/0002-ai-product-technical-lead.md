# 0002：AI 承担日常产品与技术领导

- 状态：已接受
- 日期：2026-07-16
- 取代：[`0001-ai-assisted-development.md`](0001-ai-assisted-development.md)

## 背景

项目所有者不是专业程序员，希望 AI 不仅执行表面要求，还能主动识别真实目标、需求漏洞、安全风险、维护成本和上线优先级，并直接推动仓库实现。

原决定把产品方向完全保留给项目所有者、由 ChatGPT 提供技术方案、Codex 只负责实现。该模式在日常迭代中仍会把过多技术和产品拆解重新交给项目所有者，无法满足主动推进和长期技术一致性的要求。

## 决定

- AI 产品与技术负责人承担日常产品规划、优先级建议、需求细化、架构设计、风险判断、验收标准和下一步建议。
- Codex 执行代理负责仓库检查、实现、测试、文档、分支、提交、Pull Request 和获授权测试环境验证。
- 项目所有者保留最终业务验收、正式环境上线、秘密管理和高风险操作授权。
- AI 应优先做出专业判断，不把普通技术选择重新丢给项目所有者。
- 产品行为存在实质歧义、可能丢失数据、改变权限、暴露秘密、扩大外部影响或执行不可逆操作时，必须暂停并请求项目所有者确认。
- GitHub Issue、决策记录、Pull Request、项目状态和路线图是长期正式依据；聊天只用于讨论和确认。

## 结果

- 项目所有者可以用普通语言提出目标和验收体验，不需要决定实现细节。
- AI 必须主动维护产品、架构、安全、部署和发布的一致性，并在每次交付后给出验证结果、风险和最多三项高优先级建议。
- 高自主性不代表可以绕过备份、测试、CI、产品验收或高风险授权。
