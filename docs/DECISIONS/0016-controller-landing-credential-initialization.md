# ADR 0016：入口侧单落地秘密的原子初始化与失败恢复

- 状态：已接受，初始化能力尚未接入菜单或服务器
- 日期：2026-08-08
- 关联：[ADR 0007](0007-landing-secret-and-apply-protocol.md)、[ADR 0014](0014-controller-landing-registration.md)、[ADR 0015](0015-entry-initiated-landing-root-bootstrap.md)、[Issue #220](https://github.com/DTB201/sb-user-manager/issues/220)

## 背景

一次性 root 引导、受限通道登记和 apply 已经要求入口持有 ADR 0007 定义的每落地秘密清单，但此前只有测试夹具能够准备这些材料。若交互向导直接调用现有函数，真实用户必须手工生成 SSH 密钥、密码、CA 和服务证书；任一步失败还可能留下无法判断归属的半成品。

入口状态中的 `role:"entry-controller"` 是本能力的前置角色事实。秘密初始化不能自行创建或切换角色，也不能在尚未建立并通过校验的控制器状态上运行。

## 决定

### 每落地独立材料

每台落地独立生成 Ed25519 管理私钥、64 字符 URL-safe 随机网关密码、私有 CA 证书、网关服务证书和网关私钥。网关证书覆盖调用者确认的完整 SNI，证书链、有效期、密钥匹配和主机名仍由 ADR 0007 的统一验证器复核。

CA 私钥、CSR、OpenSSL 配置、序列文件和 SSH 公钥只存在于入口 700 暂存目录。最终目录严格只保留 ADR 0007 允许的五份 600 材料；CA 私钥不会成为长期秘密，也不进入清单、备份或 apply package。

完整 SNI 只写入 root-only 暂存配置和最终 root-only 清单，不进入 OpenSSL、ssh-keygen 或 jq 的 argv。密码和私钥只通过文件或进程输出生成，不进入 argv、普通输出或日志。

### 发布与中断收敛

初始化持有控制器状态锁。入口先在秘密根目录内生成并完整验证 700 候选目录，同步五份材料后再用同文件系统 `mv` 原子发布为固定目录。清单随后由 600 临时文件生成、校验、同步并原子发布。

两个目录项无法作为一个文件系统操作共同提交，因此唯一允许的中间状态是“完整且已验证的最终秘密目录存在，清单尚不存在”。下一次同一 `landing_id`、同一 SNI 的调用必须重新验证全部材料后只补清单；不得重新生成或覆盖。清单已存在时只允许同一 SNI 的幂等确认。清单缺失但目录不完整、存在额外文件、权限错误、符号链接或所有权异常时全部失败关闭。

生成阶段的随机暂存目录和清单临时文件使用可识别的固定前缀，普通失败和信号路径及时清理。若 `SIGKILL` 或断电留下暂存对象，下一次持锁调用只会在路径、名称、所有者、权限、对象类型和允许文件集合全部可证明时清理；否则拒绝继续。

### 清理边界

后续添加向导可以清理尚未登记的秘密，但必须同时提供准确的 `landing_id` 和 SNI。清理前重新确认控制器状态中不存在该落地、五份材料完整有效、路径固定且没有额外对象；清单存在时还必须完整有效并匹配同一 SNI。初始化中断所允许的“完整目录存在、清单尚不存在”边界也可由同一严格清理函数安全收回。已登记落地、错误 SNI 或任何不可信状态一律拒绝删除。清理用单次命令删除五份固定材料，不使用不受限递归路径。

## 暂不包含

本决定不创建入口角色、不安装系统依赖、不连接落地、不接菜单、不修改入口数据面，也不轮换已登记落地的秘密。[ADR 0017](0017-controller-landing-onboarding-orchestration.md) 负责按失败阶段编排角色检查、主机指纹确认、秘密准备、一次性 root 引导、受限通道登记和首次 apply；角色路由与菜单接入仍是后续独立任务。

## 回退

撤销秘密初始化模块、测试、本文档并重新生成单脚本即可回退代码。测试中生成且尚未登记的完整秘密可用严格清理函数删除；已登记落地的秘密必须走未来的停用、轮换或移除流程，不能直接删除。
